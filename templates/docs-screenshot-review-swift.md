## Swift/native projects

When the repository already has a native capture capability, use that
capability against local or fictional fixture data and follow its existing
setup instructions. Do not assume a particular native capture tool, command,
device, or dependency: this template does not create any of them.

Review the rendered result for layout, content, and sensitive-data boundaries
before adding an image to version control. Keep any accepted capture workflow
and repository-specific launch details in the application repository.
